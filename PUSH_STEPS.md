## Step 4 — Create the GitHub repo

Open https://github.com/new in your browser:

- Repository name: `llm-security-gateway-final`

## Step 5 — Push

```bash
git branch -M main
git remote add origin https://github.com/<your-github-username>/llm-security-gateway-final.git
git push -u origin main
```

If git asks for credentials, GitHub now requires a personal access token, not your password:
- Generate one at https://github.com/settings/tokens (classic, scope: `repo`).
- Paste it when prompted for the password.

## Step 8 — Make a follow-up commit if you change anything

```bash
git add <changed files>
git commit -m "Short message describing the change"
git push
```

## Common problems

- **`fatal: remote origin already exists`** — run `git remote set-url origin <new-url>` instead of `git remote add`.
- **Push rejected because of large file** — find the file with `git ls-files -s | sort -nk1 | tail`, remove it, and use `git rm --cached <file>` before re-committing.
- **You accidentally committed `.env`** — change your Gemini key immediately and run `git filter-repo --invert-paths --path .env` (or just delete the repo and start again).
