# Knowledge bundle

Curated concepts the four specialist agents consult. Open Knowledge Format
(OKF) v0.2: one Markdown file per concept, YAML frontmatter, plain Markdown
links between them.

This is a wiki, not a document dump. A concept earns a file when explaining it
well matters more than once, and it is written to be read by a model that has
seconds, not by a human with an afternoon.
